My Multicam Video Editing Project in Adobe Premiere Pro

Watching a video from different camera angles can make storytelling more dynamic and engaging. Adobe Premiere Pro's Multicam feature allows footage recorded with multiple cameras to be edited within a single timeline.

Filming and Synchronization Process

For my personal introduction video, I recorded the same speech from two different camera angles. Using the Create Multi-Camera Source Sequence feature in Premiere Pro, I synchronized the footage through audio waveforms. This allowed me to create smooth transitions between the two cameras.

Video Editing and Visual Effects

During the editing process, I switched between camera angles to create a more engaging video. I also used intro animation, Gaussian Blur, masking, Cross Dissolve, and keyframe techniques to enhance the visual quality. At the end of the video, I created a slideshow using photographs.

What Did I Learn from This Project?

I discovered how Multicam editing simplifies the video production process and saves time. This project helped me better understand the importance of camera angles, audio and video synchronization, and creative visual effects in storytelling.

Tags: Adobe, Premiere, video editing, multicam

Responsive Web Design: Developing My Own Portfolio Website

Today, it is important for websites to display properly not only on computers but also on smartphones and tablets. Responsive design is a web design approach that improves the user experience by adapting to different screen sizes.

Designing My Portfolio Website

While developing my portfolio website, I used HTML5, CSS3, and Bootstrap. I focused on responsive layouts, proportional images, and readable content across different devices.

Mobile Compatibility and User Experience

I used a collapsible navigation menu to make browsing easier on mobile devices. I also created a design that allows users to switch between light and dark themes according to their preferences.

Testing Different Screen Sizes

Using Chrome DevTools, I examined the mobile, tablet, and desktop versions of my website and checked the images, buttons, and page layouts.

What Did I Learn from This Project?

I learned that responsive design is not only about visual aesthetics but also about accessibility, usability, and user experience. This project helped me improve my web development skills.

Tags: HTML5, CSS3, Bootstrap, responsive, web design

Automated News Collection and Data Transfer with n8n

Manually following constantly updated online news can be time-consuming. n8n is a workflow automation platform that connects different applications and helps automate repetitive tasks.

Automated News Collection

In my project, I created a scheduled workflow using the Schedule Trigger node. With the RSS Read node, I collected news headlines, links, and publication dates from DonanımHaber.

Data Transfer with Google Sheets

I worked on Google Sheets integration to organize the collected news data. The goal was to automatically transfer news information into a spreadsheet.

What Did I Learn from This Project?

This project helped me understand RSS feeds, automated data collection, and workflow integration between different platforms. I also discovered how automation can save time in everyday tasks.

Tags: n8n, RSS, Google Sheets, automation
